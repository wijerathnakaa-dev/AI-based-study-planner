# Study Planner and Academic Success Tracker

A web application designed for students to organize study schedules, manage assignments, and track academic progress.

## Features

- **Study Schedule Generator**: Creates daily study plans based on your subjects, available hours, and deadlines.
- **Study Recommendations**: Recommends which task to focus on next based on priority and due dates.
- **Focus Timer**: Tracks study sessions and logs time spent on each task and subject.
- **Tasks & Subjects**: Manage assignments, set target grades, and sort tasks by due date or priority.
- **Progress Tracking**: View study streaks, completed hours, and overall task progress.
- **Notifications**: Reminders for upcoming deadlines and overdue tasks.

## Tech Stack

- **Frontend**: React, Vite
- **Backend**: Node.js, Express
- **Database**: MongoDB

## How to Run

1. **Install dependencies**:
   ```bash
   npm run install-all
   ```

2. **Start the app**:
   ```bash
   npm run dev
   ```

- Frontend runs at: `http://localhost:5173`
- Backend runs at: `http://localhost:5000`
