# Study Planner & Academic Success Tracker

A modern web application built for students to plan study schedules, track academic performance, manage assignments, and stay focused with an intelligent study coach.

---

## 🚀 Key Features

- **Personalized Study Coach & Recommendations**: Multi-factor algorithm that prioritizes tasks based on deadlines, grade targets, difficulty, and study recency.
- **Automated Schedule Generator**: Allocates tasks into balanced daily study sessions while respecting user study hours, break preferences, and deadlines.
- **Focus Timer**: Dedicated study timer with accurate elapsed time calculation, session logging, and automatic progress updates for tasks and subjects.
- **Academic Analytics & Performance Tracker**: Track study streaks, weekly study hours, subject grade gaps, and task completion metrics.
- **In-App Notification Center**: Instant alerts for overdue assignments, deadlines within 24 hours, and study streak reminders.
- **Task & Subject Management**: Full CRUD capabilities with semester filtering, task sorting (due date, priority, creation date), and dedicated detail views.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite, React Router 7, Chart.js, Vanilla CSS Design System
- **Backend**: Node.js, Express, MongoDB (Mongoose), JWT Authentication
- **Security**: Strict CORS validation supporting local and private network IPs, ownership validation on all student resources.

## 📦 Getting Started

### Prerequisites

- Node.js (v18+)
- MongoDB running locally on `mongodb://localhost:27017`

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/wijerathnakaa-dev/Study-Planner-and-Academic-Success-Tracker.git
   cd Study-Planner-and-Academic-Success-Tracker
   ```

2. Install dependencies:
   ```bash
   npm run install-all
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

- Frontend: `http://localhost:5173`
- Backend API: `http://localhost:5000`
